# M1 实施方案:StreamDock 原生管理器 MVP(MiraDeck)

(方案与上一版相同,要点复述)

1. **git 基线**:提交 mirabox/HANDOFF.md + StreamDockProbe.swift + .gitignore(排除 probe 二进制)
2. **工程**:mirabox/ 独立 SPM 包(tools 6.2 / macOS 14+),targets:StreamDockKit(驱动库)+ StreamDockHarness(CLI 验证)+ MiraDeck(SwiftUI 应用,子 agent 交付后加入)+ 单测
3. **驱动层(我写)**:HIDTransport(IOHIDManager 热插拔/串行写队列/心跳 7s)、StreamDock293S(蛇形键位/命令字节/包构造纯函数)、DeviceController(@MainActor @Observable 状态机,连接→校准→重画)、IconRenderer(标题/颜色/图片→CGImage→JPEG≤10240B)
4. **API 冻结后并行派工**:子 agent A = ConfigStore(JSON 持久化)+ ActionRunner(6 种动作);子 agent B = MiraDeckApp/AppModel/EditorView;产物由我逐一审查合入
5. **验收(做好后我过一遍)**:swift test 全绿;退出官方 app 后 harness 画满 18 键+按键事件打印(需要你届时按键);MiraDeck 运行时空闲 CPU<2%、内存与配置持久化检查;结束后恢复官方 app 运行
6. 明确不做:背景图/LED(M2 前)、插件宿主(M2)、签名分发

风险预案:按键报告字节偏移未物理验证过 → harness 打印原始字节兜底;CGEvent 需辅助功能授权 → 首次运行引导;媒体键 CGEvent 易踩坑 → osascript 兜底。
